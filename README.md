# cyber-habit-tracker
A Gamified cyberpunk-themed interactive habit tracker.
CYBER-HABIT // Quest Tracker HUD is a gamified, cyberpunk-themed interactive daily habit tracker and productivity HUD built with pure HTML5, CSS3, and modern JavaScript. You can check out the live web app at https://tanusreepittala.github.io/cyber-habit-tracker/. The repository includes features like RPG leveling and XP progression where you earn XP by completing daily protocols based on their difficulty level, rank up from Cyber Novice to Legendary Netrunner, and trigger level-up announcements with celebratory visual effects. It also features daily streak multipliers, a matrix analytics HUD with real-time completion percentage gauges, lifetime XP logs, and a 7-day protocol history visualizer. Additionally, it contains a web audio synthesizer for immersive cyberpunk sound effects using the browser's native Web Audio API, a CRT scanline toggle for retro arcade visual effects, and local persistence via browser localStorage. The project structure consists of index.html for UI markup and HUD layout, style.css for cyberpunk neon aesthetics and animations, and app.js for the game engine, state management, and render logic. You can run it locally by cloning the repository and opening index.html in any modern browser, and deploy it to GitHub Pages via the repository settings.
